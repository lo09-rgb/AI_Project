# GAN-MNIST

A Generative Adversarial Network (GAN) implemented from scratch using PyTorch.

## Features
- Generator Network
- Discriminator Network
- MNIST Dataset
- BCE Loss
- Adam Optimizer
- Automatic image generation after every epoch

## Tech Stack
- Python
- PyTorch
- Torchvision

## Future Improvements
- DCGAN
- CelebA Dataset
- Conditional GAN (cGAN)
- WGAN-GP
