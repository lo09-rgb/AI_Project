## 🧠 What is Artificial Intelligence?

**Artificial Intelligence (AI)** is the field of computer science focused on creating systems capable of performing tasks that normally require human intelligence.

* Understand natural language
* Recognize images and objects
* Make decisions
* Solve problems
* Learn from experience
* Generate content

### Examples

* Chatbots

* Generative AI

## 🤖 What is Machine Learning?

**Machine Learning (ML)** is a subset of AI where computers learn patterns from data and use those patterns to make predictions or decisions without being explicitly programmed for every situation.

### Simple Flow

```text
Data
  ↓
Preprocessing
  ↓
Feature Selection
  ↓
Training
  ↓
Machine Learning Model
  ↓
Prediction
  ↓
Evaluation
```

---

## 📚 Types of Machine Learning

### 1. Supervised Learning

The model learns from **labeled data**.

```text
Input Data + Correct Output
          ↓
        Model
          ↓
     New Prediction
```

Common algorithms:

* Linear Regression
* Logistic Regression
* Decision Trees
* Random Forest
* K-Nearest Neighbors
* Support Vector Machines
* Naive Bayes

---

### 2. Unsupervised Learning

The model works with **unlabeled data** and attempts to discover hidden patterns.

Common techniques:

* K-Means Clustering
* Hierarchical Clustering
* DBSCAN
* Principal Component Analysis (PCA)

---

### 3. Reinforcement Learning

An agent learns by interacting with an environment.

```text
       Environment
            ↑
            |
        Reward
            |
          Agent
            |
         Action
            ↓
       Environment
```

The objective is to maximize the total reward over time.

## ⚙️ Machine Learning Pipeline

A typical ML project follows these stages:

### 1. Collect Data

Gather relevant and useful data.

### 2. Clean Data

Handle missing values, duplicates, and incorrect information.

### 3. Explore Data

Understand relationships and patterns using data analysis and visualization.

### 4. Prepare Features

Convert raw information into meaningful features.

### 5. Split the Dataset

```text
Dataset
   |
   +---- Training Data
   |
   +---- Testing Data
```

### 6. Train the Model

The algorithm learns patterns from the training data.

### 7. Evaluate

Measure how well the model performs on unseen data.

### 8. Improve

Tune parameters, engineer features, or experiment with different algorithms.

## 🧮 Example: Linear Regression

Linear Regression attempts to find a relationship between input variables and a continuous output.

The basic equation is:

```text
y = mx + c
```

Where:

* `y` → predicted value
* `x` → input
* `m` → slope
* `c` → intercept

The model learns the best values of `m` and `c` from the available data.
